# Contributing

This repository is the Docker deployment package for VectorMBE — Compose files,
Caddy configuration, and the built web UI.

- Issues with **deployment** (Compose, Caddy, container setup, the docs here)
  belong in this repository.
- Issues with **VectorMBE itself** belong in
  [radsilent/VectorMBE](https://github.com/radsilent/VectorMBE), where the
  source lives.

If you are unsure which, open it here and it can be moved. Reports that the
setup steps did not work on your machine are especially welcome — they have only
been tested on a handful of configurations.
